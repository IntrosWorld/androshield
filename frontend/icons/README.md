# Carbon icon assets

This sprite contains unmodified path data from IBM's `@carbon/icons` package, version 11.85.0.

- Source: https://www.npmjs.com/package/@carbon/icons
- Design guidance: https://carbondesignsystem.com/elements/icons/usage/
- Upstream repository: https://github.com/carbon-design-system/carbon
- License: Apache-2.0

The symbols are stored locally so the dashboard does not require an icon CDN or an additional runtime dependency.
